# SmartTube VOT

**SmartTube VOT** — независимая неофициальная сборка SmartTube для Android TV с интеграцией закадрового голосового перевода видео Яндекс VOT.

Приложение разрабатывается как отдельный вариант плеера (`stvot`) с изолированным идентификатором пакета `io.github.kiryuhak.smarttubevot.stable`, что позволяет устанавливать его параллельно с оригинальным SmartTube без конфликтов и перезаписи данных.

---

## Возможности

- **Закадровый голосовой перевод видео**: мгновенный перевод иностранных видеороликов на русский язык через API Яндекс Переводчика.
- **«Живой голос»**: поддержка нейросетевых реалистичных голосов при наличии токена авторизации.
- **Авторизация через Яндекс ID**: безопасный вход по QR-коду / коду устройства для получения OAuth-токена прямо с телевизора.
- **Интеллектуальный автозапуск**: автоматический запуск перевода только для видео с иностранными звуковыми дорожками (русскоязычные дорожки не запускают перевод впустую).
- **Независимая установка**: собственный пакет `io.github.kiryuhak.smarttubevot.stable` не конфликтует со стабильной или бета-версиями оригинального SmartTube.
- **Адаптивная графика для TV**: полноценный широкоэкранный баннер и оптимизированная иконка для Android TV и Google TV Launcher.
- **Встроенное обновление**: прямое получение свежих версий приложения из репозитория GitHub.

## Установка

### Способ 1. Приложение «Downloader» на Android TV (рекомендуется)
1. Установите приложение **Downloader** из Google Play Store на вашем телевизоре или ТВ-приставке.
2. Откройте Downloader и введите прямую ссылку на скачивание:
   `https://github.com/Kiryuhak/SmartTube-VOT/releases/latest/download/smarttube_vot.apk`
3. Дождитесь загрузки и подтвердите установку APK.

### Способ 2. Через USB-накопитель (флешку)
1. Скачайте `smarttube_vot.apk` на компьютер.
2. Скопируйте APK-файл на USB-флешку.
3. Подключите флешку к ТВ и откройте любой файловый менеджер (например, X-plore или File Commander).
4. Запустите APK и нажмите **Установить**.

### Способ 3. Через Android Debug Bridge (ADB)
```bash
adb connect <IP-адрес_вашего_ТВ>
adb install -r smarttube_vot.apk
```

## Обновление

В SmartTube VOT интегрирован механизм автоматической проверки обновлений:
1. Приложение проверяет наличие новых версий, обращаясь к защищённому манифесту:
   `https://github.com/Kiryuhak/SmartTube-VOT/releases/latest/download/smarttube_vot.json`
2. При выходе релиза на экране появляется диалоговое окно со списком изменений на русском языке.
3. При нажатии кнопки **«Обновить»** приложение автоматически скачивает свежий APK и передаёт его системному установщику Android TV.
4. Проверить обновления вручную можно в любое время: `Настройки -> О программе -> Проверить обновления`.

## Авторизация Яндекс ID

Для использования многоголосых нейросетевых моделей («Живой голос») требуется привязать аккаунт Яндекса:
1. Откройте плеер во время воспроизведения любого видео.
2. Нажмите на иконку перевода или перейдите в `Настройки -> Перевод видео (VOT) -> Яндекс OAuth`.
3. На экране появится QR-код и ссылка с кодом устройства.
4. Отсканируйте QR-код смартфоном или перейдите на страницу авторизации в браузере и подтвердите вход.
5. При успешной авторизации токен сохранится в зашифрованных настройках приложения, а режим «Живой голос» активируется автоматически.

> **Безопасность:** Токен авторизации используется исключительно для выполнения локальных запросов к API перевода с вашего ТВ. Никакие учетные данные, логины и токены не передаются сторонним серверам.

## Живой голос

- Опция **«Живой голос»** позволяет озвучивать ролики продвинутыми нейросетевыми дикторами с естественными интонациями и сохранением оригинального тембра.
- При отсутствии токена Яндекс ID доступен стандартный закадровый перевод.
- Громкость оригинального видео и громкость озвучки настраиваются независимо в меню плеера.

## Сборка из исходников

Для локальной сборки проекта необходимы:
- JDK 17
- Android SDK (Build-Tools 34.0.0, SDK Platform 34)

### Сборка Debug APK:
```bash
# Сборка flavor stvot
./gradlew assembleStvotDebug

# Сборка стандартного flavor ststable
./gradlew assembleStstableDebug
```
Собранные APK появятся в каталоге:
`smarttubetv/build/outputs/apk/stvot/debug/`

### Сборка Release APK:
Для подписанной сборки создайте файл `keystore.properties` в корне проекта со свойствами:
```properties
storeFile=path/to/release.jks
storePassword=your_store_password
keyAlias=your_key_alias
keyPassword=your_key_password
```
Затем выполните:
```bash
./gradlew assembleStvotRelease
```

## CI/CD

В проекте настроена автоматизация на базе GitHub Actions:
1. **Pull Request CI (`.github/workflows/ci.yml`)**:
   - Запускается на PR и проверяет форматирование (`git diff --check`).
   - Собирает `assembleStvotDebug` и `assembleStstableDebug`.
   - Проверяет строгую изоляцию библиотек (гарантирует, что `Yandex AuthSDK` не попадает в официальный `ststable`).
2. **Release Pipeline (`.github/workflows/release.yml`)**:
   - Атомарная сборка при создании тега формата `v*-vot.*`.
   - Подпись через защищённые GitHub Secrets без коммита ключей в репозиторий.
   - 8 уровней валидации (проверка сигнатур `apksigner`, монотонность `versionCode`, package name, сопоставление с `CHANGELOG.md`).
   - Публикация релизов в GitHub Releases с файлом обновления `smarttube_vot.json`.
3. **Upstream Watcher (`.github/workflows/check-upstream.yml`)**:
   - Ежедневный мониторинг апстримов `yuliskov/SmartTube` и `vsvoice/SmartTube`.
   - Безопасное тестирование слияния в отдельной ветке без прямого вмешательства в `main`.
   - Создание PR на русском языке для удобного ревью мейнтейнером (или Issue при конфликтах).
