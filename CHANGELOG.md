# История изменений

Все заметные изменения в проекте SmartTube VOT документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [32.45-vot.1] - 2026-09-10

### Добавлено
- Интеграция закадрового голосового перевода видео через Яндекс (VOT) для Android TV.
- Поддержка «Живого голоса» и безопасной авторизации через Яндекс ID (OAuth).
- Автоматическое включение «Живого голоса» при наличии авторизованного токена.
- Отдельный flavor `stvot` с собственным `applicationId` (`io.github.kiryuhak.smarttubevot.stable`) для независимой установки параллельно с официальным SmartTube.
- Механизм встроенного обновления приложения через релизы GitHub (`Kiryuhak/SmartTube-VOT`).
- Адаптивная иконка и полноразмерный TV-баннер высокого разрешения для Android TV Launcher.
- Инфраструктура непрерывной интеграции (CI) для проверки Pull Request.
- Автоматизированный атомарный релизный процесс с контролем цифровой подписи APK.
- Мониторинг обновлений апстримов SmartTube и VOT без автоматического слияния в `main`.

### Изменено
- Улучшена безопасность логирования OAuth: токен авторизации замаскирован и не выводится в логи отладки.
- Оптимизирован алгоритм автоперевода: решение принимается строго по языку выбранной аудиодорожки (русская дорожка исключает запуск, иностранная запускает, неопределённая дорожка ожидает ручного запуска).
- Усовершенствована нормализация языковых меток (строгий учёт локалей `ru`, `ru-*`, `rus`, `russian`).

### Исправлено
- Исправлено отображение иконки приложения в лаунчере Android TV (устранён чёрно-серый ореол и уменьшенный масштаб).
- Исправлена ошибка Leanback UI при обработке 32-битных кодов запроса (`requestCode`) для безопасной работы `ActivityResultRegistry`.
- Устранён ложный автозапуск закадрового перевода на русскоязычных видеороликах.
