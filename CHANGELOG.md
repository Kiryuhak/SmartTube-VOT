# История изменений

Все заметные изменения в проекте SmartTube VOX (ранее SmartTube VOT) документируются в этом файле.
SmartTube VOX — новое название проекта SmartTube VOT.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [Unreleased]

### Добавлено
- Ненавязчивый TV-оверлей прогресса перевода (`VotProgressOverlay`) в правом нижнем углу экрана (acrylic glass HUD), отображающий статус подготовки («Ожидание очереди перевода...», «Перевод формируется...»), обратный отсчёт времени ожидания (`~мм:сс`) или таймер прошедшего времени, а также индикацию готовности или ошибки.
- Адаптивный таймаут ожидания длительных очередей перевода с контролем пульса ответа сервера (heartbeat timeout до 90 сек на запрос и абсолютный потолок 25 минут для длинных видео от 2 часов).
- Визуальный оранжевый акцент иконки кнопки перевода в плеере во время ожидания очереди (`INDEX_PENDING`) и кратковременная индикация ошибки (`INDEX_ERROR`).
- Быстрый переключатель «Живой голос» в контекстном меню микшера громкости перевода при активной авторизации Яндекс ID.
- Архитектурный хук `isLivelyVoiceSpecificFailure` для обнаружения специфических сбоев Живого голоса.

### Улучшено
- Исправлено зависание и обрыв запросов перевода для длинных видео (2+ часа) на стороне сервиса перевода: ограничен начальный интервал опроса (до 45 сек) и добавлен экспоненциальный retry (до 3 попыток с задержкой 5 сек) при временных сбоях сети/HTTP `IOException`.
- Ручной запуск перевода по кнопке пульта ДУ активирует визуальный оверлей прогресса, в то время как фоновый умный автоперевод остаётся бесшумным.
- Оверлей не перехватывает фокус пульта ДУ (DPAD navigation), кликабельность отключена, оверлей плавно исчезает через 3.5 секунды после старта воспроизведения перевода или при ошибке.
- Гарантированная очистка состояния оверлея, таймеров и фоновых задач опроса при переключении видео и выходе из плеера.

## [32.45-vot.7] — Pulse

### Добавлено
- Единый раздел настроек «Закадровый перевод (Яндекс)» в настройках плеера.
- Статус авторизации Яндекс ID («Авторизован» / «Не авторизован») без отображения токена.
- Возможность быстрого входа и выхода из Яндекс ID прямо из настроек.
- Полный ребрендинг проекта в SmartTube VOX: обновлены иконки, ТВ-баннеры и логотипы ST VOX.

### Изменено
- Ручной ввод токена вынесен в отдельный подпункт.
- Статусы ручного запуска перевода оптимизированы для пульта ДУ.
- Фоновый автоперевод иностранного контента работает без навязчивых уведомлений.
- Улучшена совместимость со встроенным механизмом автообновления (smarttube_vox.json и fallback на smarttube_vot.json).

### Улучшено
- Автоматическое восстановление громкости основного плеера при сбоях дорожки перевода.
- Корректная обработка протухших сессий авторизации Яндекс ID.
- Строгая изоляция между flavor stvot и upstream ststable.

## [32.45-vot.4] — Echo

### Добавлено
- Однократное предложение авторизации через Яндекс ID после входа в SmartTube для активации «Живого голоса».
- TV-friendly onboarding с кнопками «Войти в Яндекс» и «Позже».

### Изменено
- Громкость оригинала при переводе по умолчанию снижена с 15% до 5%.
- Громкость перевода по умолчанию остаётся 100%.
- Существующие пользовательские настройки громкости не перезаписываются.

### Улучшено
- Онбординг не показывается повторно после выбора «Позже», Back/Cancel или успешной авторизации.
- Онбординг не показывается, если Яндекс уже авторизован.
- ststable остаётся без Yandex onboarding.

## [32.45-vot.1] - 2026-09-10

### Добавлено
- Интеграция закадрового голосового перевода видео через Яндекс (VOT) для Android TV.
- Поддержка «Живого голоса» и безопасной авторизации через Яндекс ID (OAuth).
- Автоматическое включение «Живого голоса» при наличии авторизованного токена.
- Отдельный flavor `stvot` с собственным `applicationId` (`io.github.kiryuhak.smarttubevot.stable`) для независимой установки параллельно с официальным SmartTube.
- Механизм встроенного обновления приложения через релизы GitHub (`Kiryuhak/SmartTube-VOT`).
- Адаптивная иконка и полноразмерный TV-баннер высокого разрешения для Android TV Launcher.
- Инфраструктура непрерывной интеграции (CI) для проверки Pull Request.
- Автоматизированный атомарный релизный процесс с контролем цифровой подписи APK.
- Мониторинг обновлений апстримов SmartTube и VOT без автоматического слияния в `main`.

### Изменено
- Улучшена безопасность логирования OAuth: токен авторизации замаскирован и не выводится в логи отладки.
- Оптимизирован алгоритм автоперевода: решение принимается строго по языку выбранной аудиодорожки (русская дорожка исключает запуск, иностранная запускает, неопределённая дорожка ожидает ручного запуска).
- Усовершенствована нормализация языковых меток (строгий учёт локалей `ru`, `ru-*`, `rus`, `russian`).

### Исправлено
- Исправлено отображение иконки приложения в лаунчере Android TV (устранён чёрно-серый ореол и уменьшенный масштаб).
- Исправлена ошибка Leanback UI при обработке 32-битных кодов запроса (`requestCode`) для безопасной работы `ActivityResultRegistry`.
- Устранён ложный автозапуск закадрового перевода на русскоязычных видеороликах.
